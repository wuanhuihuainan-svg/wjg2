# 失败诊断与最小修复

先选一个主因，再给出局部替换词。

| 主因 | 典型现象 | 最小修复 |
|---|---|---|
| 空间漂移 | 门/桌/窗换位 | 重附白模与锚点表；只重生该镜 |
| 人物漂移 | 瞬移、换装、换手 | 在首帧重述位置、朝向、服装和手持物 |
| 摄影机失控 | 穿墙、乱转、丢主体 | 将运动降为固定/短横移；锁定起止位置 |
| 节奏过载 | 动作同时发生 | 切成两个镜头，每镜一个完成动作 |
| 接片断裂 | 下一镜起点不等于上一镜收尾 | 用上一镜尾帧先生成下一镜首帧，再生视频 |
| 参考冲突 | 白模、人物图、首尾帧矛盾 | 以 `space_bible` 为唯一空间真源，重做冲突参考 |
| 串人/换脸 | 多人物参考职责不清、合照映射错误 | 回到 `asset_registry`，一人一 ID；重建该段合成首帧，只让人物参考约束身份 |
| 场景吞人物 | 人物图背景与场景图竞争 | 使用空场景底图和干净人物板重建首帧；视频只用一个主驱动图 |
| 首帧贴纸感 | 人物尺度、透视、光影未融合 | 修正合成首帧，不靠视频运动掩盖 |
| 轴线/方向翻转 | 相邻段屏幕左右或出入画方向不一致 | 用中性建立镜头、反应镜头或遮挡剪点重建轴线 |
| 音画不容纳 | 对白时长超过片段，动作被压缩 | 回到音频账本，延长/拆分片段或减少画面动作 |

两次局部修复仍失败时，不要继续增加负面词；按顺序尝试：重建首帧、减少参考、简化动作/机位、移动剪点、改用插入/反应/遮挡镜头、缩短片段，最后才要求新资产。
