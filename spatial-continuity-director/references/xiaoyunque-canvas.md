# 小云雀画布节点与模型路由

只在运行环境是小云雀画布时读取本文件。小云雀是执行层：它保存资产、展示白模/调度图、提供模型选择并提交生成任务；Skill 不自建平行画布，也不假定固定 API 参数。

## 最小画布链路

`剧本节点 + 原始资产节点`
→ `资产登记/角色别名绑定节点`
→ `参考污染与冲突检查节点`
→ `场景候选 9 宫格节点（仅场景资产缺失时）`
→ `人物候选 9 宫格节点（每位缺失人物各一个）`
→ `用户选择资产节点`
→ `白模图节点（用户选择生图模型）`
→ `俯视调度图节点（人物彩色路线 + 黄色机位层）`
→ `spatial_plan 节点`
→ `人物运动、动作因果与时空碰撞校验节点`
→ `调度确认节点`
→ `SD2.0 场景提示词注入节点（场景提示词 + 人物提示词）`
→ `每段参考输入矩阵 + 合成首帧节点`
→ `首帧 QC 与资产/调度确认节点`
→ `视频模型选择节点`
→ `模型时长能力检查节点`
→ `全局提示词 + 逐镜/逐秒提示词节点（按视频模型分支）`
→ `提示词确认节点`
→ `接片策略选择节点`
→ `连续视频节点 1 → 首/中/尾抽帧 QC → 稳定尾帧或编辑接棒节点 → 连续视频节点 2 …`

白模图和俯视调度图必须引用同一个已选场景资产与锚点 ID。人物路线使用不同颜色，摄影机使用黄色；交叉或共享通道必须带时间码、等待点与净空说明，同一时刻不得发生碰撞。任何用户编辑资产绑定、白模、人物选择、调度图或合成首帧后，后续计划与提示词节点标记为过期，需重新确认。

## 模型选择

### 白模与调度图（生图）

- 由用户在画布的可用生图模型中选择；可为 GPT 生图、香蕉 2 或新增模型。
- Skill 只要求输出满足白模约束：同一空间、无无关人物/文字、门窗家具位置稳定、可识别锚点；不绑定某一家生图模型的专有语法。
- 记录 `image_generation.provider` 与 `image_generation.model`，确保重生时使用同一选择；用户可主动更换模型，但更换后需要重新确认白模。

### 连续视频（视频）

- 用户在 `SD2.0 / Seedance 2.x` 和 `MiniMax H3` 中选定一个视频分支；画布使用对应 API 节点提交。
- 该选择决定提示词适配文件和允许附加的参考资产；不改变已经确认的空间计划。
- 若画布支持多个视频模型，可把同一已确认计划复制为对比节点；每条结果独立保存自己的尾帧和 `handoff_state`，不得交叉承接。

## 双确认与一键提交

画布内部可以保留细粒度状态，但 manifest 只暴露两级用户确认：

1. `asset_and_keyframes_confirmed`：场景/人物候选已选、角色别名与资产职责已确认，白模、时空走位、参考输入矩阵和每段合成首帧通过 QC；
2. `model_and_prompts_confirmed`：模型能力已在当前节点核验，全局视觉圣经、逐段/逐秒提示词、音频账本、接棒策略和回退剪点已确认。

任一前置状态变化都会使对应确认过期。

资产选择和绑定完整、人物物理/时空碰撞、调度、合成首帧、场景人物提示词与视频提示词确认均为 `true`，且模型能力、接片策略和版本有效时，才启用生成。每个视频节点带入一个 `primary_driver`、实际可附加的辅助参考、完整场景描述、对应片段与逐秒提示词、前段接棒和 `start_state`/`handoff_state`。同一连续链必须在上一段通过抽帧 QC 后再运行下一段。

约 30 秒项目先做复杂度预检。只有节点时长允许且风险低时启用单条实验一镜节点；其他情况创建 2–4 个连续片段，并显示接棒方式与“非原生一镜到底”提示。

## 失败重生

空间漂移、人物漂移或接片失败时，复制失败视频节点而非重做整条链路；保持相同资产和已确认提示词，只替换失败镜的最小修复词。若白模锚点本身被改动，必须从确认门重新开始。
