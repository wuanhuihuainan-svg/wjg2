# 人物运动、因果与时空碰撞校验

在输出调度图或视频提示词前读取。校验对象是人物和摄影机随时间的占用关系，而不是俯视图线条是否永远相交。

## 时空路线

每条路线拆成带时间窗的段：`from`、`to`、`start_s`、`end_s`、`occupancy_zone`、`action`。图上可让不同路线交叉或复用狭窄通道，但必须满足：

- 同一时间不占用同一碰撞区；
- 先后通过时有等待点或明确先行者；
- 交接/对话发生在相邻站位，不让身体落点重合；
- 摄影机跟拍可与人物复用同一走廊，但必须保持可执行的前后/侧向净空；
- 镜头看不见的安全距离不要虚构精确数值，以可见关系和实际场景尺度判断。

人物继续使用不同颜色，摄影机使用黄色，方便审阅；颜色不是生成模型的动作约束，不应在成片画面中出现。

## 动作因果链

复杂动作先写为：

`执行者 → 起始位置/姿态 → 动作与方向 → 接触对象/连接 → 可见反应 → 结束位置/状态`

门、道具、座椅和身体接触尤其要明确：

- 开门：到达把手侧 → 对应手接触把手 → 门改变状态 → 人物过门槛；
- 坐下/起身：身体对齐座位 → 重心变化 → 接触/离开座面 → 稳定姿态；
- 递接：递出者与接收者到达各自站位 → 道具接触 → 接收者握稳 → 归属更新一次；
- 转角：减速与转头/转身可见 → 屏幕运动方向重新建立。

结果没有可见原因、力的方向矛盾、物体连接凭空变化或角色落点冲突时，禁止用“突然、然后”掩盖。

## 物理可执行性

1. 路线只经过已知可通行区域；未知区不得当捷径。
2. 起步、移动、减速、转身、停步和操作都有可见时间。
3. 初末朝向与对白对象、道具或下一动作一致。
4. 手别、道具归属、门窗和家具状态只在可见动作后更新。
5. 多人同时动作不过载；次要人物可静止、等待或以反应替代移动。

## 轴线与视线

登记对话轴、人物屏幕左/右、视线目标和出入画方向。同一连续关系内保持一致；确需跨轴时，用中性正面镜头、可见绕行或新的建立镜头重建空间。

## 校验结果

`spatial_plan.json` 至少记录：

- `spatiotemporal_collision_verified`；
- `physical_motion_verified`；
- `causality_verified`；
- `axis_and_eyeline_verified`；
- 所有共享通道的 `time_separation` 或 `clearance_note`。

任一为 `false` 时先按以下顺序修复：错时移动 → 加等待点 → 简化人物动作 → 固定/简化摄影机 → 拆段 → 要求新的场景信息。不得靠增加负面词通过校验。
